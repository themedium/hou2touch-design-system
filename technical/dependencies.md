## 6. Porting dependency checklist per target

### TouchDesigner
- **Needs:** a GLSL TOP, a Constant/Null to hold uniforms, a Text or HTML TOP for the overlay labels.
- **Font:** install the four files from `fonts/` into the Text TOP's font folder.
- **Dither:** set the GLSL TOP resolution to `round(w/CELL) × round(h/CELL)` and use *Nearest* filtering.
- **Mask:** the title knockout can be done with a Text TOP rendered to a texture and sampled in the GLSL TOP.

### Three.js
- **Needs:** `three` (WebGLRenderer), a `RawShaderMaterial` or `ShaderMaterial`, `NearestFilter` on the
  render target.
- **Fonts:** `FontLoader` + `typeface.json` from the Bebas OTF, or the WOFF2 via `opentype.js`.
- **Colour:** `THREE.Color` → the family colour as a `vec3` uniform.
- **No extra runtime deps** beyond three.

### After Effects
- **Needs:** the fonts installed locally; the dither must be rendered as a PNG/EXR sequence from a real
  renderer (AE's built-in Halftone is not the same ordered Bayer and will not match).
- **Honest limitation:** AE cannot reproduce `b8` exactly without a plug-in or a pre-baked dither LUT.

### Blender
- **Needs:** the fonts installed; a compositor node setup that replicates the Bayer threshold.
- **Honest limitation:** the Bayer threshold is trivial in the compositor (a Math node with a pre-baked
  8×8 image), but the *per-fragment* `b8(gl_FragCoord.xy)` semantics (cell-space, not pixel-space) must
  be reproduced by rendering at cell resolution and upscaling.

### Web / print
- The system is a **browser-native** technology. The most faithful port is: HTML + CSS + WebGL, exactly
  as the site already is. For print, render the canvas at 2× and downsample to the target resolution so
  the dither cells land on whole device pixels.
